# QA · UAT 재실행

프로젝트 루트에서 `node tests/qa-uat/run-all.mjs`를 실행합니다.

135개 걸킨 시나리오를 먼저 파일로 생성하고, 로컬 Playwright MCP 서버에 MCP 프로토콜로 연결해 실제 브라우저에서 실행합니다. 일반 Playwright 테스트 러너로 대체하지 않습니다. 기존 제품 코드는 수정하지 않으며 원본 작업 데이터는 별도 폴더에 복사합니다.

4317·4318 포트가 사용 중이면 실행을 중단합니다. 테스트에 필요한 서버만 생성하고 종료합니다. GLB/PNG 등록, 데이터 삭제와 공개는 테스트 사본에서만 수행합니다. 브라우저 응답 지연·오류 주입은 각 시나리오의 격리된 브라우저 안에서만 사용합니다.

현재 컴퓨터에 설치된 Playwright MCP 경로를 기본으로 사용합니다. 다른 컴퓨터에서는 `QA_PLAYWRIGHT_MCP_CLI`에 Playwright MCP의 `cli.js` 절대 경로를 지정해야 합니다. Microsoft Edge, Node.js와 프로젝트 의존성도 필요합니다.

결과는 `docs/qa/2026-09-08/SUMMARY.md`, `report.html`, `results.csv`에 생성됩니다. 확인된 결함이나 UAT 기준 확인 항목이 있으면 종료 코드는 1입니다. 결과의 '수용 기준 확인'은 즉시 생성 후 설정창을 닫는 기존 동작에 대한 사용자 경험의 판단 사항이며, 확정된 제품 결함과 분리했습니다.

현재 실행에서 대기·초점 기준을 보정한 재시험 이력은 결과 JSON에 남겨 두었습니다. 향후 전체 재실행은 새 실행 시작 이후의 결과만 집계합니다.
