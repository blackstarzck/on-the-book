## 관찰의 범위

첫 화면, 시작 안내, 집의 문, 버스 정류장까지 직접 조작했다. 사이트 전체 완주나 모든 이스터에그 발견을 완료한 것은 아니다. 고구마 수집과 이스터에그는 안내에서 확인했으며 구체적인 전체 목록은 추정하지 않았다. 접근에 따른 장면 변화는 화면으로 확인했지만 원본 사이트 내부의 거리 계산이나 애니메이션 코드를 분석한 것은 아니다.

## 책 탐험으로 바꾼 방식

- 책을 고르면 펼친 책 위의 3D 장면으로 들어간다.
- 땅을 누르거나 방향키·WASD·모바일 방향 버튼으로 이동한다.
- 물체의 반응 거리 안에 들어가면 뛰기·회전·부유·흔들기·파일 내 애니메이션 중 지정한 동작을 실행한다.
- 해당 물체의 문장을 자동으로 수집한다. 반복 방문으로 수집 수가 늘어나지 않는다.
- 황금 문에 도착하거나 하단 화살표·챕터 지도를 이용해 다음 장면을 방문한다.
- 장별 한국어 이야기를 읽고 마지막 장에서 탐험 결과를 확인한다.
- 관리자에서 책, 본문, 모델, 위치·크기·회전·반응 거리·동작을 바꾼다. 임시 저장과 공개를 분리했다.

## 디자인 기준

책이라는 매체가 먼저 느껴지도록 크림색 종이, 짙은 녹색 글자, 세리프 제목, 절제된 금빛 강조색을 사용했다. 큰 3D 공간 주변에 최소한의 조작부를 두고, 관리자에는 실제 모델 미리보기와 편집 필드를 나란히 배치했다. 디자인 지침의 검색 보조 파일은 설치된 스킬에 경로 문자열만 있고 실제 실행 파일이 없어, 읽은 접근성·반응형·동작 지침을 직접 적용했다.
