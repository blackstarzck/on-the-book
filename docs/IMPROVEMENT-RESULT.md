## 확인 순서

1. [사용자 화면](http://127.0.0.1:4173/client/?book=alice&chapter=alice-1)에서 토끼에게 다가간다. 토끼가 시계를 보고 달려가면 오른쪽 열린 굴로 따라간다.
2. 복도에서 황금 열쇠를 줍고 ‘나를 마셔요’ 병을 마신다. 화면 행동 버튼 또는 화면에 초점을 둔 상태에서 E로 행동한다. 작아진 뒤 오른쪽 문 가운데로 지나간다.
3. 버섯 숲, 티 파티, 장미 정원, 마지막 장면의 행동을 이어서 경험한다. 필요하면 하단 **길 찾기 도움 → 다음 행동 위치로 안내**를 사용한다.
4. [관리 화면](http://127.0.0.1:4173/admin/)의 **장면과 이야기**에서 사건 종류를 바꾸고 저장·공개한다. 사건 소품은 탐험에서 자동 배치되며, 편집 화면에는 기존 등록 모델 배치를 표시한다.

지도와 화살표는 장면을 바로 선택하는 별도 편의 기능이다. 실제 문을 통과할 때는 사건 조건이 적용된다. 진행 상태는 브라우저에 저장된다. 관리자에서 사건 종류를 바꾸면 해당 종류의 진행을 새로 시작한다.

## 검사 결과

- 서버 검사 7개 통과: 저장·공개·잘못된 입력·모델 파일·로그인 등
- 기존 브라우저 검사에 사건 편집을 추가한 14개 항목 통과
- 새 탐험 검사 6개 항목 통과: 장 연속성, 잠긴 문, 열쇠와 크기 변화, 6장 전체 진행, 모바일·동작 줄이기, 실행 오류 없음
- 모바일 조작 2개 항목 통과: 방향 버튼 이동·발견, 터치 도움 열기와 미발견 목록 숨김
- 배포용 파일 생성 성공. 3D 공통 파일 용량 경고는 남아 있음
- 저장·공개 검사는 별도 임시 데이터 사용. 실제 관리자 작업 데이터는 변경하지 않음

## 남은 범위

원본과 같은 표현 완성도를 달성했다고 보지는 않는다. 캐릭터의 표정·정교한 관절 연기, 장면별 음향, 자연스러운 토끼굴 낙하 등은 더 제작할 여지가 있다. 이번 사건은 미리 정한 순서로 진행되며 관리자가 임의의 모든 동작·조건·소품 위치를 편집하는 도구는 아니다. 오즈에는 연결된 공간과 기존 발견을 적용했고, 고유 사건은 앨리스에 집중했다. 고정 나무·주요 장애물·문은 통과를 제한하지만 업로드 모델 전체의 모양에 맞춰 자동으로 길을 찾지는 않는다. 모바일은 브라우저 크기와 터치 입력 모사로 검증했으며 실제 휴대폰의 장시간 성능은 미검증이다.
