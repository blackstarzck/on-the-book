# 관리자 사용 안내

관리자 주소: http://127.0.0.1:4173/admin/

## 도서 보관함과 월드 편집기

첫 화면은 도서 보관함입니다. 제목 검색과 공개 대상 필터로 책을 찾고, 표지를 눌러 전체 화면 월드 편집기를 엽니다. 새 도서는 제목만으로 초안을 만들 수 있습니다. 도서 정보에서 표지 PNG, 저자, 소개, 출처와 권리 정보를 완성하세요. 공개 전에는 저자와 권리 정보가 필요합니다.

월드 왼쪽에는 모델 보관함, 오른쪽에는 선택 대상의 속성, 아래에는 챕터 목록과 배치 미니맵이 있습니다. 패널 제목을 누르면 접을 수 있습니다. 왼쪽 마우스 드래그로 회전, 오른쪽 드래그로 화면 이동, 휠로 확대합니다. 독자 체험에서는 실제 client의 조작과 시점을 사용합니다.

새 챕터는 모델과 바닥 장식이 없는 빈 월드로 시작합니다. 애니메이션 모델 카드를 바닥으로 끌면 격자에 맞춰 배치됩니다. 모델을 선택하고 X·Y·Z 축 손잡이로 이동하거나 오른쪽 좌표를 입력하세요. Y는 바닥에서의 높이입니다. 격자는 0.5·1·2 단위, 회전은 15도 단위를 사용합니다. W는 이동, E는 방향 도구, Escape는 선택 해제입니다. 실행 취소·다시 실행과 모델 복제·삭제를 지원합니다.

보관함 썸네일은 실제 3D 모델입니다. 마우스를 올리면 파일의 첫 동작이 재생됩니다. 새 등록과 새 배치는 뼈대가 연결되고 뼈대 애니메이션이 있는 GLB만 허용합니다. 기존 기본 모델은 이전 장면을 보존하기 위해 남아 있지만 새 배치는 막힙니다. 기존 모델의 정보에서 올바른 GLB로 교체하면 연결된 배치도 그 모델과 파일 동작을 사용합니다.

선택한 모델의 파일 동작을 고르고 재생해서 확인하세요. 발동 반경과 실제 적용되는 접근 범위, 충돌 반경은 오른쪽 패널에서 조절합니다. 높이·방향도 저장과 공개를 거쳐 client에 반영됩니다.

## 책과 챕터

책 정보에서 제목, 소개, 출처, 저작권 안내와 공개 여부를 관리합니다. 챕터를 추가·삭제하거나 순서를 바꾸면 사용자 화면의 이동 순서도 바뀝니다.

‘챕터와 본문’에서 공간 크기, 장면 분위기, 이야기 본문을 편집합니다. ‘오른쪽에 보여 줄 글귀’를 비우면 이야기 본문을 사용합니다.

같은 창에서 접근 배율, 카메라 여백, 페이지 분량과 순차 등장 효과를 설정합니다. 접근 배율의 기본값은 기존 화면과 같은 2배입니다. 글 상자의 높이·불투명도·흐림은 공통 디자인으로 고정됩니다. 작은 화면에서는 글 상자 높이가 화면에 맞게 줄어듭니다. 긴 글은 본문 안에서 스크롤되며 페이지 버튼은 고정됩니다.

## 바닥 화살표와 이미지

장면 위의 ‘바닥 화살표·이미지’를 누릅니다. 화살표 표시 여부, 크기, 간격과 경유지를 설정할 수 있습니다. 경유지를 선택하고 바닥을 누르거나 좌표를 입력해 이동합니다. 경유지 순서를 바꾸거나 추가·삭제할 수 있습니다. 챕터 양쪽 연결 지점은 자동으로 유지됩니다.

기본 손그림을 추가하거나 PNG 이미지를 올려 배치할 수 있습니다. 이미지를 선택하고 위치·너비·높이·회전을 조절하세요. 파란 원은 선택한 항목의 중심입니다. PNG는 5MB 이하, 가로·세로 4096 이하로 준비합니다.

처음에는 기존 자동 배치를 불러옵니다. ‘배치 적용’을 누른 뒤부터 해당 챕터의 바닥 배치는 모델 이동과 별개로 유지됩니다. 화살표를 모델 위치에 다시 맞추려면 ‘모델 위치로 경유지 재설정’을 누르세요. 적용하지 않고 닫으면 편집 전 배치를 유지합니다. 적용한 뒤 임시 저장·체험·공개 순서로 확인하세요.

## 3D 모델과 범위

‘3D 모델 보관함’에서 GLB 파일을 등록하고 월드로 드래그해 배치합니다. 배치한 모델의 위치, 크기, 회전, 접근 시 동작을 관리합니다.

장면의 금색 원은 애니메이션과 글 노출의 실제 반응 범위입니다. 붉은 원은 캐릭터 중심이 들어갈 수 없는 충돌 범위이며 캐릭터의 너비까지 포함합니다. 모델 크기나 충돌 반경을 바꾸면 두 범위도 갱신됩니다.

충돌은 모델 중심의 고정된 원형 범위입니다. 복잡하거나 긴 모델은 ‘충돌 반경’을 직접 맞춘 뒤 체험하며 조절하세요. 애니메이션에 따라 충돌 범위가 흔들리지는 않습니다.

## 공개 전 확인과 공개

‘독자 체험’은 모달 없이 현재 월드에서 시작합니다. 캐릭터가 공중에서 착지한 뒤 마우스를 누른 채 움직이거나 방향키·WASD로 조작합니다. 체험 자체는 저장이나 공개를 하지 않습니다. ‘편집으로 돌아가기’를 누르면 기존 편집 시점과 선택 상태를 복원합니다. 충돌, 접근 애니메이션, 글과 카메라를 함께 확인할 수 있습니다.

체험은 공개 중인 내용이나 독자의 읽기 기록을 변경하지 않습니다. 관리자 비밀번호가 설정되어 있으면 로그인한 관리자만 임시 내용을 불러올 수 있습니다.

월드 우측 상단의 X·Y·Z 축 도구를 누르면 양쪽 축 방향에서 볼 수 있습니다. 축 도구를 드래그해 시점을 회전할 수도 있습니다. 배치 가능한 애니메이션 모델은 보관함 상단에 표시됩니다.

‘임시 저장’은 관리자 작업만 저장합니다. 확인을 마치고 ‘사용자 화면에 공개’를 누르면 공개 대상으로 설정한 책이 반영됩니다. 이미 열려 있는 사용자 화면은 새로고침하세요.
# 바닥 이미지와 배치 간격

## 메인·보조 모델

- 각 챕터의 첫 배치는 메인, 이후 배치와 복제는 보조입니다. 기존 챕터는 저장된 첫 모델을 메인으로 지정하며 좌표와 본문은 유지합니다.
- 오른쪽 ‘챕터 모델’에서 모델을 선택합니다. 보조의 속성 패널에서 ‘메인 모델로 지정’을 누르면 화살표와 본문 연결이 바뀝니다. 메인 삭제 시 남은 모델 중 대체 메인을 선택합니다.
- 자동 경로는 메인만 경유하며 기존 수동 경유지는 안내에 사용하지 않습니다. 직접 배치한 이미지 화살표는 유지됩니다.
- 모든 모델은 개별 접근 시 애니메이션이 작동합니다. 본문·독서 카메라는 메인만 실행합니다. 관리자와 미니맵에서 별은 메인, 점은 보조입니다.
- 모든 모델의 발동 범위 겹침 제한은 유지합니다. 빈 챕터는 초안 저장이 가능하지만 공개 대상 도서는 모든 챕터에 메인이 있어야 합니다.

- 왼쪽 **바닥 이미지** 목록에서 화살표·나뭇잎·회중시계·찻잔·책 이미지를 월드로 드래그합니다. PNG도 등록해 배치할 수 있습니다. 등록한 PNG는 월드에 배치하고 저장하면 다시 열 때 목록에 나타납니다.
- 배치한 이미지를 클릭하면 같은 이동 도구와 우측 패널로 X·Y·Z 위치, 방향, 가로·세로 크기를 수정하거나 삭제할 수 있습니다. 실행 취소와 저장을 지원합니다.
- 자동 경로 화살표는 모델의 실제 애니메이션 발동 영역 밖에 표시됩니다. 수동으로 배치한 이미지는 관리자가 정한 위치를 유지합니다.
- 새 모델 배치·이동·반경 변경 시 발동 영역이 다른 모델과 겹치면 제한됩니다. 높이를 바꿔도 수평 발동 영역 기준이며, 이웃 챕터도 검사합니다. 복제는 가까운 빈자리를 찾습니다. 기존 배치는 임의로 이동하지 않습니다.
