# 검증 결과

2026-09-07, Windows의 Microsoft Edge에서 확인했습니다. 테스트는 별도의 임시 데이터 폴더와 서버를 사용했으며 제공되는 기본 책장 데이터에 테스트 항목을 남기지 않았습니다.

## 통과한 확인

- 서버 검증 7개: 샘플 데이터 무결성, 잘못된 배치와 모델 연결 차단, 임시 저장의 파일 보존, 공개 데이터 분리, 중복 저장 충돌, 외부 요청 차단, GLB 업로드 검증, 비밀번호 로그인·로그아웃을 묶어 확인했습니다.
- 브라우저 검증 13개: 첫 화면, 접근 시 문장 수집, 중복 수집 방지, 챕터 이동·주소 복원·기록 유지, 책 선택·종료, 임시 저장·공개, GLB 업로드·미리보기, 업로드 모델의 실제 장면 배치와 발견, 모델 제거, 책·챕터 생성과 순서 변경, 375px 모바일, 동작 줄이기, 브라우저 실행 오류 유무를 확인했습니다.
- 추가 검증 2개: 실제 3D 화면의 황금 문 위치를 클릭하여 캐릭터가 걸어가고 다음 챕터로 넘어가는 동작, 812×375 가로 화면을 확인했습니다. 이 과정에서 콘솔 오류도 없었습니다.
- 배포용 묶음 생성 성공. 3D 라이브러리가 포함된 공통 파일이 약 634KB(전송 압축 기준 약 165KB)여서 빌드 도구의 500KB 권장 크기 알림은 남아 있습니다. 실행 실패는 아닙니다.

## 검증 중 수정한 문제

- 선택 메뉴의 이름 연결을 명확하게 하여 보조 도구로도 동작을 선택할 수 있게 수정했습니다.
- 모바일에서 숨겨지던 ‘이 장의 발견’ 버튼을 표시했습니다.
- 모바일 책장 버튼의 줄바꿈과 수집 개수의 위치를 수정했습니다.
- 사이트 아이콘을 추가해 브라우저의 불필요한 404 오류를 없앴습니다.
- 모델 위치를 캐릭터가 도달할 수 있는 범위로 제한했습니다.

## 증거 파일

- `browser-results.json`: 브라우저 검증 결과
- `portal-results.json`: 실제 화면 클릭으로 문을 통과한 검증 결과
- `screenshots/`: PC·모바일 화면 확인 기록. 통합 테스트 중 촬영한 화면에는 테스트용 모델이나 문구가 포함될 수 있습니다.
- `preview/`: 기본 콘텐츠 그대로 촬영한 사용자 확인용 화면

## 확인하지 않은 환경

외부 인터넷 배포, 다수의 동시 관리자, 대형·복잡한 실제 제작 모델 전체, Safari/iOS 실기기, 독자 계정 간 동기화는 검증 범위에 포함하지 않았습니다. 현재 실행은 로컬 컴퓨터와 단일 관리자 작업을 기준으로 합니다.
