# 비교 증거에 따른 보완 계획

## 목표와 완료 기준

1. 작은 책 모형 교체를 연결된 탐험으로 바꾼다. 하나의 공간에서 장 사이를 걷고, 카메라가 따라가며 앞 장면이 화면 밖으로 사라지는지 확인한다.
2. 앨리스에 고유한 사건을 만든다. 토끼가 시계를 확인하고 달려간 뒤 굴이 열리며, 다음 복도에서 열쇠와 병을 만나 작아져야 문을 통과할 수 있어야 한다.
3. 이후 장마다 몸집 회복, 차 따르기, 장미 칠하기, 카드 흩날리기를 직접 조작한다. 관리자도 장면의 사건 종류를 고르고 저장·공개할 수 있게 한다.
4. 탐험 중에는 캐릭터 중심의 가까운 시점, 팔다리 걷기, 구역별 배경을 사용한다. 모바일에서 책 전체를 축소하지 않는다.
5. 자동 이동은 도움 메뉴로 제공한다. 평소에는 미발견 대상의 이름을 감추고 짧은 상황 안내와 조작만 표시한다.

## 검증

- 기존 저장·공개·업로드·책 선택 기능 회귀 검사
- 조건 전에는 문 통과 불가, 사건 후 통과 가능, 장 이동 시 같은 화면 유지, 재방문·새로고침·지도 이동 검사
- 데스크톱 및 390×844 화면, 키보드·화면 방향 버튼, 동작 줄이기 설정 검사
- 구현 후 실제 브라우저 화면을 촬영해 보고서와 함께 보관

## 범위

앨리스 여섯 장에 사건을 구현하고 모든 책의 장을 연결한다. 원본 캐릭터나 모델을 복제하지 않고 기존 직접 제작 모델을 보완한다. 실제 휴대폰 성능과 전문 제작 수준의 캐릭터 연기는 별도 검증·제작이 필요하다.
