# 이미지 대기 화면

책 표지·메인 그림·장면·배너, 소개 페이지의 주요 그림과 확대 보기, 관리자 편집·업로드 목록·저장된 모델 썸네일에는 실제 그림의 작은 흐린 미리보기를 표시합니다. 로고·아이콘·장식과 실시간 3D 화면은 대상에서 제외합니다. 기존 이미지 다운로드 시점은 유지합니다.

- 원본을 표시할 준비가 되면 180ms 동안 전환합니다. 이미 준비된 원본과 기기의 동작 줄이기 설정에서는 전환을 생략합니다. 원본 표시 후 대기 배경을 제거해 투명 이미지에 색이 남지 않습니다.
- 미리보기가 없으면 대표색, 둘 다 없으면 불러오는 중 안내를 표시합니다. 실패 안내와 이미지 미등록 상태를 구분합니다.
- 업로드 때 긴 변 32px 이하의 WebP와 투명 부분을 제외한 대표색을 만듭니다. 전달 문자열은 이미지마다 2KB 이하입니다. 파일 정보의 별도 항목에 저장하고 기존 응답에 함께 전달합니다. 공개 화면에는 공개된 파일의 정보만 전달합니다.
- 기존 파일 정보 생성은 `node --env-file=.env scripts/backfill-image-previews.mjs`로 실행합니다. 원본과 책 내용을 먼저 백업하고, 완료된 항목은 건너뜁니다. 원본 파일·주소·공개본을 변경하지 않습니다. 소개 페이지의 고정 그림은 화면 빌드 때 포함합니다.
- 확인은 `npm test`, 양쪽 빌드와 `node tests/image-previews.mjs`로 진행합니다. 후자는 임시 저장소만 사용하는 실제 브라우저 검사입니다. 운영 화면을 되돌리는 방법은 [배포 안내](DEPLOYMENT.md#되돌리기)를 따릅니다. 추가된 파일 정보 항목은 이전 서버와 호환되므로 DB를 되돌릴 필요가 없습니다.

이번 작업은 기다리는 동안 보이는 화면을 개선합니다. 원본 용량과 다운로드 속도는 바꾸지 않습니다.
