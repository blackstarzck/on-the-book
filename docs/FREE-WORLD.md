# 자유 이동과 접근 애니메이션으로 변경

## 적용 내용

- 수집·보상·행동 버튼·사건 진행·잠긴 문·크기 퍼즐·완료 화면을 제거했습니다. 모델 가까이에서 지정된 애니메이션이 반복되고, 벗어나면 기본 자세로 돌아가며 다시 접근하면 처음부터 재생됩니다.
- 챕터 기본 크기는 28×15에서 64×56으로 늘었습니다. 앨리스 여섯 장은 가로 384로 이어집니다. 전후좌우로 자유롭게 움직이며 카메라가 따라갑니다. 모델을 만나지 않고도 다음 장으로 이동할 수 있습니다.
- 자동으로 추가하던 사건 소품과 보상 꽃을 제거했습니다. 평지와 길 위에 관리자가 등록·배치한 챕터별 모델을 표시합니다.
- 관리자는 챕터별 가로 40~120, 세로 40~100 범위에서 공간 크기를 정하고 모델 위치·배율·회전·접근 거리·애니메이션을 관리합니다. 배치 미리보기와 사용자 화면은 동일한 좌표를 사용합니다. 공간 밖으로 모델이 나가는 크기 변경은 안내와 함께 막습니다.
- 기존 데이터는 `data/library-before-free-world-*.json`에 백업했습니다. 기존 배치의 간격을 3배로 넓혔으며, 재시작할 때 중복 적용하지 않습니다. 이전 게임 기록은 사용하지 않습니다.

## 확인 결과

서버·이전 데이터 변환 검사 9개와 브라우저 검사 11개 통과. 실제 클릭 이동, 조건 없는 장 이동, 세로 방향으로 넓은 이동, 접근·이탈·재접근 반응, 관리자 크기·좌표·거리 저장과 별도 공개, 애니메이션이 있는 GLB 업로드·재생, 모바일 방향 버튼과 동작 줄이기 설정을 확인했습니다. 실행 중인 4173번 서버에 반영하고 관리자·사용자 화면을 다시 열어 확인했습니다.

[사용자 화면](http://127.0.0.1:4173/client/) · [관리자](http://127.0.0.1:4173/admin/)

## 범위

참고 사이트의 이동·근접 반응 방향을 적용한 것으로 원본 모델이나 모든 세부 움직임을 그대로 재현한 것은 아닙니다. 현재 지형은 챕터별 평지이며, 자유로운 지형 조형 도구와 실제 휴대폰 장시간 성능 검증은 포함하지 않습니다. 동작 줄이기 설정에서는 모델 애니메이션을 정지합니다.
