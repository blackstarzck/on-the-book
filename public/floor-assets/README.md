# 바닥용 원본 벡터 에셋

이 프로젝트를 위해 직접 그린 SVG입니다. 참고 화면의 방향 안내·연필 낙서 분위기를 참고했으며 원본 사이트의 이미지를 추출하지 않았습니다.

- arrow.svg: 붉은 손그림 방향 화살표
- leaves.svg: 잎사귀
- pocket-watch.svg: 회중시계
- tea-cup.svg: 찻잔
- open-book.svg: 펼친 책
- graph-paper.svg: 반복 가능한 모눈종이 바탕

손그림은 투명 배경이며 크기를 바꿔 재사용할 수 있습니다. 실제 바닥에는 이 파일을 불러와 표시합니다.
